## Build

Requires macOS with Xcode Command Line Tools installed.

```bash
make
```

This produces the `ls` executable in the current directory.

```bash
make clean   # remove object files and binary
```

### Manual compile (without make)

```bash
cc -Wall -Wextra -std=c11 -O2 \
   -isysroot $(xcrun --show-sdk-path) \
   -D_DARWIN_C_SOURCE \
   -o ls main.c options.c sort.c print.c output.c color.c \
   -lutil
```
